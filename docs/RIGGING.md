# Phase 2 리깅 설계 / v0.2.0

## 계층과 좌표

Part.parentId와 Deformer.parentId는 디포머/그룹 ID 또는 null이다. 그룹, 회전, 워프 노드를 같은 계층에서 조합하며 최대 64개, 파츠에 적용되는 부모 최대 12단계를 허용한다. 부모는 디포머만 될 수 있다. 순환, 누락 참조, 전체 노드 ID 중복은 저장/읽기와 부모 변경 시 거부한다. 레이어 그리기 순서는 기존 parts 배열로 유지하며 계층을 바꿔도 앞뒤 순서를 바꾸지 않는다.

파츠 로컬 정점 → 파츠 transform → 부모 워프 → 부모 pivot 기준 transform → 상위 부모 순으로 월드 좌표를 계산한다. 화면/카메라는 별도다. 부모에 파츠를 감싸는 새 노드는 identity 변환이어서 생성 순간 모양이 유지된다. 기존 부모로 다시 연결하는 작업은 **로컬 좌표 유지**이며 변형된 부모에서는 화면상 위치가 달라질 수 있음을 UI에 표시한다.

그룹은 계층 컨테이너와 transform, 회전 디포머는 pivot 중심 회전/배율/이동, 워프 디포머는 규칙 제어 격자의 bilinear 변위 보간과 transform이다. 격자 밖의 점은 가장자리 변위를 연장한다. 현재 UI가 만드는 워프는 2×2 셀 / 3×3 제어점이다. 커스텀 격자 해상도는 UI에서 제공하지 않는다.

RigEvaluator를 렌더링/히트 테스트/드래그에 함께 사용한다. 회전과 배율은 해석적 역변환, 워프는 제한된 Newton 반복으로 역변환한다. 접히거나 특이한 워프에서 역변환이 불가능하면 편집 오류를 표시하고 NaN 좌표를 기록하지 않는다. 부모 워프 자체 제어점은 자기 워프의 역변환 없이 조정할 수 있다.

## 파라미터와 키폼

기존 Part Binding 외에 Parameter.deformerBindings를 추가한다. 디포머 키폼에는 transform과 워프 제어점 배열을 저장한다. 각 파라미터의 키 사이를 선형 보간한다. 여러 파라미터는 기본 모양 대비 위치·회전·정점·제어점 변위를 더하고, 배율은 기본 배율 대비 비율을 곱한다. 최종 배율은 0.01~100 범위로 제한한다. 이는 독립 파라미터 합성이며 2차원 격자 조합 키폼/보정 키폼 편집은 아직 제공하지 않는다.

키폼 초안은 선택 파라미터만 분리한 포즈다. renderProject는 임시 키폼을 삽입해 나머지 파라미터와 실시간으로 합성한다. 기록 시 다른 파라미터의 변형을 중복 저장하지 않는다. pivot과 부모는 키폼 바깥의 공통 리깅 구조다. 미기록 초안은 저장/Undo 대상이 아니다. 파라미터가 연결된 디포머의 기본 변형은 잠그고 키폼 편집으로 안내한다.

## 메쉬 토폴로지

삼각형 내부를 탭해 정점을 추가한다. 정점·UV와 모든 관련 파라미터 키폼을 같은 barycentric 가중치로 보간하고 해당 삼각형을 3개로 나눈다. 모서리/기존 정점과 너무 가까운 추가는 거부한다.

내부 정점 삭제는 연결된 삼각형 fan의 경계를 확인하고 ear clipping으로 구멍을 채운다. 각 키폼의 같은 인덱스를 제거하고 전체 삼각형 인덱스를 갱신한다. 외곽 정점은 이미지 범위 보호를 위해 삭제를 막는다. 비정상/교차 fan은 거부한다. Undo 한 번으로 토폴로지와 모든 키폼을 함께 복원한다. 최대 1024정점 / 6144삼각형 인덱스다. 전체 문서의 키폼 포함 정점/제어점 100,000개, 키폼 8,192개 상한으로 리깅 데이터 증가를 제한한다.

## 포맷 v2

새 파일은 version=2. v1을 읽으면 추가 필드가 비어 있음을 확인하고 v2로 변환한다. 앱 내부의 v1 프로젝트는 최초 열기 시 .v1copy 원본을 보존한다. 기존 v1 파일에 디포머 데이터가 들어 있으면 거부한다. v2는 Phase 1 앱에서 읽을 수 없으므로 외부 원본을 별도로 보관한다. ZIP/PNG/JSON의 기존 용량 제한과 전체 검증을 유지한다.

## 편집과 삭제

부모의 숨김과 잠금은 하위 파츠/디포머에 상속된다. 계층 삭제는 하위 파츠와 연결된 바인딩까지 삭제하므로 개수를 표시하는 확인창을 거친다. Undo로 전체를 복원할 수 있다. 모델 이미지 캐시는 기존과 같이 즉시 삭제하지 않는다.

## 제외 범위

알파 윤곽 자동 메쉬, 외곽 정점 삭제, 수동 삼각형 연결, 임의 워프 해상도 UI, 다차원 조합 보정 키폼, 타임라인/PSD/영상/Cubism 호환은 포함하지 않는다. FPS 및 저메모리 성능은 실물 기기 검증 전 보장하지 않는다.
