# Phase 2 검증

v0.2.0 소스 구현 후 검증 진행 중. 통과 여부는 실제 CI 결과를 확인한 뒤 기록한다.

JVM: 기존 10개 회귀 테스트 + 회전축/부모 순서, bilinear 워프, 격자 밖 변위, 회전/워프 역좌표, 독립 파라미터 합성, 리깅 ZIP 왕복, 순환/누락/충돌 ID 거부, 상속 잠금/숨김, 계층 삭제/Undo, 토폴로지/UV/키폼 동기화, 내부 정점 재삼각분할, 특이 워프, v1 변환, 잘못된 디포머 데이터 테스트.

Android: 기존 5개 + 그룹→회전→워프→파츠와 복수 파라미터 편집/저장/새 Activity 복원, 실제 ModelSurface 터치 이벤트의 역좌표 이동, OpenGL 결과 이동 픽셀 비교, v1 원본 보존 및 v2 저장 검증.

실물 기기 수동 조작·GPU/FPS/저메모리 테스트는 수행하지 않았다. 기존 툴체인/Actions로 빌드하며 새 외부 라이브러리는 추가하지 않았다.
