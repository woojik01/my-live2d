# 개발 단계

Phase 1(v0.1.0): 오프라인 프로젝트/PNG/레이어/격자 메쉬/눈 키폼/Undo. 이전 검증 기록은 VALIDATION.md.

Phase 2(v0.2.0): 그룹/회전/워프 계층, 피벗/제어점, 독립 복수 파라미터 키폼, 정점 삽입/내부 삭제와 키폼 동기화, v1→v2 호환. 검증 기록은 PHASE2_VALIDATION.md. 외곽 정점 편집, 워프 해상도 UI, 조합 보정 키폼은 추가 고도화 과제다.

Phase 3(v0.3.0): 파라미터 애니메이션 클립/트랙/프레임 키 포맷, 선형/유지 보간, 길이·FPS·루프·재생·스크러빙, 키 이동/삭제, 여러 클립 저장을 구현했다. 검증과 남은 제한은 PHASE3_VALIDATION.md에 기록한다.

Phase 4 (진행 중): 투명 PNG 애니메이션 프레임 ZIP 내보내기와 알파 영역 자동 메쉬를 구현했다. CPU 삼각형 래스터화로 파라미터/디포머 평가 결과를 프레임마다 저장하며 OpenGL 오프스크린 FBO는 사용하지 않는다. 자동 메쉬는 알파 기준/여유/분할 수를 지정하는 보수적 셀 격자이며 정확한 곡선 외곽선 추출은 후속 과제다. 다음은 GIF/영상 인코딩, 프로파일링 기반 캐시/VBO 최적화, 태블릿/스타일러스 지원이다. PSD는 Android 파서·메모리·라이선스 조사 후 별도 결정한다. Cubism 호환은 별도 기술/권리 검토 전 지원으로 표시하지 않는다. 범위와 검증은 PHASE4_EXPORT.md 및 PHASE4_MESH.md.

기능 브랜치 → 자동 테스트/빌드 → APK 검증 → PR → 사용자 승인 후 병합. 앞 단계가 미병합이면 해당 기능 브랜치를 기준으로 PR을 쌓고 기본 브랜치는 수정하지 않는다. 날짜/FPS는 실제 검증 전 약속하지 않는다.


리깅 개편 1차: 2차원 조합 보정(파츠·회전·워프), 기본 파라미터, 워프 분할 변경, v4 마이그레이션을 추가한다. 모바일 UI 개선 PR 위에 쌓는다. PSD, 외곽선 기반 메쉬, 마스크, 물리, 자체 런타임 및 Cubism 형식 호환은 아직 구현되지 않았다. 각 단계는 실제 Android 기기 성능 및 사용성 검증이 필요하다.
