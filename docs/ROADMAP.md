# 후속 개발 단계

Phase 1 안정화: 실물 스마트폰/태블릿 PNG 작업 흐름, 세로/가로 회전, 강제 종료 복구, 메모리 사용량, GL 컨텍스트 손실, 장시간 정점 편집, 파일 공급자별 내보내기 검증. 슬라이더 Undo 단위 개선과 캐시 GC. 실제 사용성 확인 후 완료 여부를 판단한다.

Phase 2: 그룹/계층 데이터 마이그레이션, 회전 디포머 → warp 격자 → 부모/자식 변환, 임의 정점 추가/삭제와 삼각분할, 복수 파라미터 키폼 공간 보간. 각 단계마다 저장 왕복과 좌표 불변식 테스트를 추가한다.

Phase 3: 별도 Animation/Track/Keyframe 데이터, 시간 샘플러, easing, 타임라인 터치 선택/이동, 루프/재생, 애니메이션 목록. 눈 깜빡임·호흡 예제는 실제 파라미터 트랙으로 제공한다.

Phase 4: 알파 경계 메쉬 생성, offscreen FBO 투명 PNG 시퀀스 → 영상/GIF 내보내기 검토, 프로파일링 기반 캐시/VBO 최적화, 태블릿·스타일러스 지원. PSD는 파서의 Android 호환성/메모리/라이선스를 조사한 후 별도 PR로 결정한다. Cubism 호환은 별도 기술·권리 검토 전에는 계획된 지원으로 표시하지 않는다.

각 작업은 기능 브랜치 → 자동 테스트 → APK 검증 → PR → 사용자 승인 후 병합. 완료일과 성능 수치는 검증 전 약속하지 않는다.
