# 개발 단계

Phase 1(v0.1.0): 오프라인 프로젝트/PNG/레이어/격자 메쉬/눈 키폼/Undo. 이전 검증 기록은 VALIDATION.md.

Phase 2(v0.2.0): 그룹/회전/워프 계층, 피벗/제어점, 독립 복수 파라미터 키폼, 정점 삽입/내부 삭제와 키폼 동기화, v1→v2 호환. 현재 검증 기록은 PHASE2_VALIDATION.md. 외곽 정점 편집, 워프 해상도 UI, 조합 보정 키폼은 추가 고도화 과제다.

Phase 3: Animation/Track/Keyframe 포맷과 시간 샘플러, 타임라인의 터치 선택/추가/이동/삭제, 길이·보간 설정, 재생/정지/루프, 여러 애니메이션 관리. 눈 깜빡임과 호흡 예제를 실제 파라미터 트랙으로 구현한다. 파일 왕복·시점별 평가·재생 중 화면 회전·Undo를 검증한다.

Phase 4: 알파 윤곽 자동 메쉬, FBO 기반 투명 PNG 시퀀스, GIF/영상 내보내기, 프로파일링 기반 캐시/VBO 최적화, 태블릿/스타일러스 지원. PSD는 Android 파서·메모리·라이선스 조사 후 별도 결정한다. Cubism 호환은 별도 기술/권리 검토 전 지원으로 표시하지 않는다.

기능 브랜치 → 자동 테스트/빌드 → APK 검증 → PR → 사용자 승인 후 병합. 앞 단계가 미병합이면 해당 기능 브랜치를 기준으로 PR을 쌓고 기본 브랜치는 수정하지 않는다. 날짜/FPS는 실제 검증 전 약속하지 않는다.
