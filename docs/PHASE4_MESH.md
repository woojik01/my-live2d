# Phase 4 — 알파 영역 자동 메쉬

## 사용 방법

1. PNG 파츠를 선택하고 **속성 → 알파 영역 자동 메쉬**를 누릅니다.
2. 긴 변 분할 수(4~24), 알파 기준(1~255), 가장자리 여유(0~16픽셀)를 지정합니다.
3. **생성** 후 정점/셀 수 안내를 확인합니다. 메쉬 모드에서 정점을 직접 편집할 수 있습니다.
4. 눈 개폐 키폼 또는 사용자 키폼을 새로 만들고 파라미터 슬라이더로 확인합니다.
5. 저장하면 새 메쉬, UV, 삼각형, 키폼을 기존 v3 프로젝트에 함께 보관합니다.

메쉬를 재생성하면 **선택 파츠의 메쉬 키폼만 초기화**합니다. 다른 파츠의 키폼, 디포머, 계층 연결, 파츠의 위치/회전/배율은 유지됩니다. Undo/Redo는 이전 메쉬와 키폼을 함께 복원합니다. 잠긴 파츠, 키폼 초안 편집 중, 애니메이션 재생 중에는 생성할 수 없습니다.

## 알고리즘과 제한

- 원본 PNG의 알파를 읽어 기준 이상 픽셀의 경계와 여유 픽셀을 계산합니다. 기본 기준 1은 희미한 가장자리까지 포함합니다. 높은 기준은 옅은 픽셀을 제외하므로 결과가 잘릴 수 있습니다.
- 경계 내부에 이미지 비율을 따르는 격자를 만들고, 대상 픽셀과 여유 영역이 닿는 셀만 삼각형 두 개로 구성합니다. 빈 셀과 쓰이지 않는 정점을 제거합니다.
- 경계는 격자 단위의 보수적 근사입니다. 정확한 곡선 윤곽 추출이나 Delaunay 삼각분할이 아닙니다. 분할 수가 낮으면 작은 구멍/섬 사이 간격이 메워질 수 있고, 대각선 셀은 모서리를 공유할 수 있습니다.
- 기준 이상 픽셀은 셀에 포함되며, UV와 로컬 좌표는 원본 이미지 기준을 유지합니다. 투명 여백을 잘라도 파츠 위치나 텍스처 배치가 바뀌지 않습니다. 완전 투명 이미지 또는 기준에 맞는 픽셀이 없으면 기존 편집 상태를 유지하고 오류를 표시합니다.
- 최대 24×24셀, 625정점, 3,456삼각형 인덱스로 기존 프로젝트 한도 안에 있습니다. 입력은 기존 최대 2048×2048입니다.
- 픽셀 수에 비례하는 순회와 작은 2차원 누적 배열을 사용합니다. 알파는 픽셀당 1바이트, 색상은 한 행만 별도 복사하며, 입력 비트맵은 추출 직후 해제합니다. 생성은 UI 스레드 밖에서 실행합니다.
- 새 외부 라이브러리나 인터넷 연결을 사용하지 않습니다. 정교한 외곽선 추출과 자동 정점 배치는 후속 과제입니다.

## 자동화 검증 범위

`AlphaMeshTest`(JVM): 투명 여백/UV/원점 유지, 분리 영역과 큰 구멍, unsigned 알파/기준/여유, 1픽셀 폭 이미지, 불균일 셀, 고정 난수 마스크의 픽셀 포함/결정성, 삼각형 면적과 간선 수, 최대 이미지/정점 예산, 잘못된 옵션/빈 마스크, 대상 키폼 초기화, Undo/Redo, 프로젝트 ZIP 복원.

`AlphaMeshDeviceTest`(Android): 실제 PNG 비트맵 가져오기, 생성 대화상자 입력 검증, 알파 추출과 UI 생성 결과 일치, Undo/Redo 키폼 복원, 새 메쉬 눈 개폐 보간, 저장/열기, 완전 투명 PNG 생성 실패 후 상태·이력 유지.

실행 결과는 해당 PR의 Actions와 테스트 보고서에서 확인합니다. 이 문서는 테스트 범위를 설명하며 실행 성공을 의미하지 않습니다. 실물 스마트폰/태블릿, 스타일러스, 저메모리 및 처리 시간/FPS 계측은 별도 검증이 필요합니다.
