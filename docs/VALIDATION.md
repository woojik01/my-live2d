# Phase 1 검증 기록

이 문서는 최종 빌드/CI 결과 확인 후 갱신한다. 현재 소스에 테스트가 있는 항목은 실제 실행 결과와 구분한다.

JVM 테스트: 두 눈 키폼 보간과 ZIP 왕복, 메쉬 UV/인덱스와 정점 이동 저장, 사용자 키폼과 경계값, Undo/Redo 분기, 카메라/파츠 좌표 왕복과 화면 크기 변경, 레이어 순서/표시/잠금/투명도, 잘못된 버전/인덱스/NaN, 손상 JSON/ZIP와 누락 이미지, 경로 탈출/메타데이터 용량 제한, 잘못된 키폼/이미지 크기.

Android 계측 테스트: 실제 PNG 디코딩/두 파츠 리깅/내부 파일 저장/Repository 재생성 후 다시 열기, 잘못된 PNG 거부, Activity 재생성 후 Compose 캔버스/툴바 유지. 실제 실행 여부는 CI 결과로 확인한다.

실물 기기 수동 테스트는 아직 수행하지 않았다. 파일 선택기 다중 선택, 정점 선택/핀치 체감, 시스템 화면 회전, 외부 저장소 공급자, 저메모리 강제 종료, 60FPS는 별도 검증이 필요하다.

로컬 환경: JDK 17 및 SDK 35 설치. Gradle의 Java 네트워크 연결이 실행 환경 프록시에 연결되지 않아 의존성 해석이 실패했다. 이 실패를 소스 컴파일 또는 테스트 성공으로 처리하지 않는다. GitHub Actions 빌드를 사용해 검증한다.
