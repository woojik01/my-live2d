첫 리깅 시작하기

  1. 분리된 PNG 파츠를 불러오고 캔버스에 배치합니다.
  2. 파츠를 선택하고 회전 또는 워프 디포머로 감쌉니다.
  3. 파라미터를 추가하고 값을 선택한 다음 현재 값 키폼 편집을 누릅니다.
  4. 메쉬 정점 또는 디포머를 조정하고 키폼 기록을 누릅니다.
  5. 파라미터 슬라이더를 움직여 결과를 확인합니다.
  6. PC 단축키: V 선택, M 메쉬, F 전체 보기, +/− 확대·축소, Ctrl+Z 실행 취소, Ctrl+Shift+Z 또는 Ctrl+Y 다시 실행.

프로젝트는 기기에 자동 저장됩니다. 정기적으로 JSON으로 내보내 백업하세요. Android용 기존 .mylive2d 파일은 이 버전에서 열 수 없습니다.
