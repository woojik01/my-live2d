# My Live 2D — v0.2.0 / Phase 2

Android 스마트폰·태블릿용 독립 2D 캐릭터 모델 편집기. Kotlin + Jetpack Compose + OpenGL ES 2.0. 핵심 편집은 오프라인으로 동작하며 INTERNET 권한과 계정/서버를 사용하지 않습니다. 자체 `.mylive2d` ZIP/JSON/PNG 포맷을 사용하고 Cubism SDK·독점 소스·공식 파일 호환을 포함하지 않습니다.

Phase 2 빌드·APK 서명 검증 성공. JVM 25개와 Android API 35 에뮬레이터 7개 테스트 통과, Lint 오류 0개·경고 17개. [검증한 APK 다운로드](https://github.com/woojik01/my-live2d/actions/runs/39759563949/artifacts/12417895971) · [Phase 2 검증 보고서](docs/PHASE2_VALIDATION.md) · [PR #2](https://github.com/woojik01/my-live2d/pull/2). [Phase 1 검증 기록](docs/VALIDATION.md)은 이전 버전 기록입니다. 실물 기기·60FPS는 검증하지 않았습니다.

## 빌드 / 설치

- Android 8.0(API 26) 이상 / OpenGL ES 2.0
- JDK 17 / Android SDK 35 / Build Tools 35.0.0
- Android Studio에서 루트 폴더 열기 → Gradle Sync → app 실행
- `./gradlew :core:test :app:assembleDebug :app:lintDebug`
- Windows: `gradlew.bat :core:test :app:assembleDebug :app:lintDebug`
- APK: `app/build/outputs/apk/debug/app-debug.apk`
- [Actions](https://github.com/woojik01/my-live2d/actions): 성공한 `Android editor` 실행의 `my-live2d-phase2-debug` 아티팩트에서 `app-debug.apk` 설치. 테스트용 `app-debug-androidTest.apk`는 일반 설치 대상이 아닙니다.

CI는 실행별 디버그 키를 사용합니다. 기존 버전을 삭제하기 전에 프로젝트를 `.mylive2d`로 내보내 보관하세요. v1 파일을 이 버전에서 가져올 수 있지만 새 v2 파일은 Phase 1 앱에서 열 수 없습니다.

도구 버전은 재현성을 위해 Gradle 8.11.1 / AGP 8.9.2 / Kotlin 2.1.20 / Compose BOM 2025.04.01로 고정했습니다. 최신 버전이라는 의미가 아닙니다.

## 두 눈 깜빡임

1. `☰` → 새 프로젝트 → `+ PNG`에서 눈 PNG 두 개를 선택합니다. 이미지와 기본 4×4 셀(25정점) 메쉬가 생깁니다.
2. **파츠**에서 선택해 캔버스에서 배치합니다. **속성**에서 위치/회전/배율을 입력한 뒤 ✓로 적용합니다.
3. 파라미터 추가: `눈 개폐`, 최소 0 / 기본 1 / 최대 1.
4. 각 눈을 선택해 같은 파라미터의 **눈 개폐 키폼**을 만듭니다. 최소는 닫힘, 최대는 열림이며 중간을 선형 보간합니다.
5. 사용자 모양: 원하는 값 → **현재 값 키폼 편집** → 정점 드래그 → 하단 **키폼 기록**.
6. 저장 후 앱을 다시 열면 마지막 프로젝트를 복원합니다. `☰` → 프로젝트 내보내기에서 이미지와 리깅을 포함한 파일을 저장합니다.

## 회전·워프·그룹

1. 파츠를 선택하고 **파츠** 패널의 `+ 회전`을 누르면 새 회전 디포머가 해당 파츠의 부모가 됩니다. 생성 순간 모양은 유지됩니다.
2. 다른 파츠도 함께 묶으려면 그 파츠의 **속성 → 부모**에서 같은 디포머를 고릅니다. 기존 부모 연결 변경은 로컬 좌표를 유지하므로 이미 변형된 부모에서는 화면상 위치가 바뀔 수 있습니다.
3. **속성**의 회전·배율·이동과 회전축 X/Y로 조정합니다. 주황색 축 끝점을 드래그하면 회전, 중심점을 드래그하면 이동합니다.
4. `+ 워프`는 선택 요소를 2×2 셀 / 3×3 제어점 격자로 감쌉니다. **격자** 모드에서 제어점을 드래그합니다. 격자를 끄면 중심 이동/회전 손잡이를 사용합니다.
5. 선택한 디포머에 파라미터를 추가합니다. 예: `얼굴 기울기`, 최소 -30 / 기본 0 / 최대 30. 최대 값 → 키폼 편집 → 회전 30 → 기록. 최소 값에서도 회전 -30 키폼을 기록합니다.
6. 회전 디포머를 선택한 상태에서 `+ 워프`, `+ 그룹` 등을 추가해 계층을 중첩할 수 있습니다. 노드를 다시 선택하면 그 노드의 속성을 편집합니다.
7. 여러 파라미터를 연결할 수 있습니다. 키폼 편집 중 다른 파라미터는 미리보기에 계속 반영되며 선택 파라미터의 변형만 기록됩니다. 위치·회전·정점·제어점 변위를 합산하고 배율 비율을 곱합니다. 다차원 조합 보정 키폼은 아직 없습니다.

부모의 숨김/잠금은 하위에 적용됩니다. **선택 계층 삭제**는 확인창의 하위 요소도 삭제하며 Undo로 복원할 수 있습니다.

## 메쉬 토폴로지 / 조작

- **메쉬 생성 / 재생성**: 1~24행/열의 규칙 격자. 해당 파츠 키폼을 초기화하며 Undo로 복구합니다.
- **이동**: 메쉬 모드에서 정점을 드래그합니다. 키폼이 연결된 파츠는 키폼 편집에서 수정하세요.
- **정점 +**: 삼각형 내부를 탭합니다. UV와 모든 관련 키폼도 함께 보간합니다. 모서리 바로 위의 추가는 거부합니다.
- **정점 −**: 내부 정점을 탭합니다. 구멍을 재삼각분할하며 외곽 정점은 보호합니다. 접히거나 교차한 fan은 삭제를 거부합니다.
- 한 손가락: 선택 요소/정점/손잡이 편집. 빈 곳: 카메라 이동. 두 손가락: 확대·이동.
- **정밀**: 드래그 이동량 20%. **스냅**: 파츠/메쉬를 10 모델 단위로 맞춤. **그리드**: 100 모델 단위 기준선.
- **전체 보기**: 표시된 파츠의 최종 변형을 기준으로 카메라 맞춤.
- Undo/Redo 최대 40단계. 카메라/선택/테마/언어는 편집 이력 밖입니다.
- 작은 화면은 좌우 패널을 접어 캔버스를 확보하고, 큰 화면은 양쪽 패널을 열 수 있습니다.
- `☰`: 한국어/English, 다크/라이트, 최근 프로젝트, 가져오기/내보내기. 프로젝트 이름을 누르면 이름 변경.

## 저장과 제한

- 새 파일은 포맷 v2. v1을 읽으면 변환하고 앱 내부의 기존 v1은 최초 열기 시 `.v1copy` 원본을 보존합니다. 최근 목록의 프로젝트 삭제 시 이 내부 원본도 삭제합니다.
- 자동 저장 약 0.8초, ON_STOP 저장, 임시 파일/백업/원자적 교체. OS 즉시 종료나 전원 차단까지 무손실을 보장하지 않습니다.
- `*`는 명시적 저장 이후 변경. 자동 저장 후에도 명시적 저장 전까지 유지됩니다. 미기록 키폼 초안과 Undo 이력은 프로세스 종료 후 복구되지 않습니다.
- PNG 파일당 16 MiB, 가져오기 시 최대 변 2048로 샘플링. 프로젝트당 32이미지 / 총 16,777,216픽셀 / 64파츠 / 64디포머 / 파츠 부모 최대12단계 / 32파라미터 / 바인딩당32키폼.
- 키폼 포함 전체 정점/제어점 100,000개와 전체 키폼 8,192개 상한을 둡니다.
- 메쉬 최대1024정점 / 6144삼각형 인덱스. 워프 UI는 2×2셀 고정입니다.
- ZIP 해제 총합64 MiB / JSON8 MiB. 이미지 캐시는 Undo/공유 참조 보존을 위해 즉시 청소하지 않아 디스크 사용량이 늘 수 있습니다.
- 워프가 접히거나 특이해지면 하위 드래그의 역변환을 거부할 수 있습니다. 부모 워프의 제어점을 먼저 조정하세요.
- 배경의 체크무늬는 투명 영역의 편집 미리보기이며 알파 결과물 내보내기는 아직 없습니다.
- 60FPS는 목표입니다. 실물 기기 성능과 저메모리 환경은 별도 검증이 필요합니다.
