# My Live 2D

Android 스마트폰·태블릿용 독립적인 2D 캐릭터 모델 편집기. **Phase 1 / 0.1.0** 소스입니다. Kotlin + Jetpack Compose + OpenGL ES 2.0을 사용합니다.

Cubism SDK나 독점 파일 포맷을 사용하지 않습니다. `.mylive2d`는 자체 ZIP + JSON + PNG 포맷입니다. 핵심 편집에 네트워크·회원가입이 필요하지 않으며 앱은 인터넷 권한을 요청하지 않습니다.

## 설치 / 빌드

- Android 8.0 (API 26) 이상, OpenGL ES 2.0 지원 기기
- 개발: JDK 17, Android SDK 35 / Build Tools 35.0.0
- Android Studio에서 루트 폴더 열기 → Gradle Sync → app 실행
- CLI: `./gradlew :core:test :app:assembleDebug :app:lintDebug`
- Windows: `gradlew.bat :core:test :app:assembleDebug :app:lintDebug`
- APK: `app/build/outputs/apk/debug/app-debug.apk`
- [GitHub Actions](https://github.com/woojik01/my-live2d/actions) → 성공한 Android Phase 1 실행 → `my-live2d-phase1-debug` 아티팩트
- 디버그 APK는 개발 검증용이며 스토어 배포 서명이 아닙니다.

Gradle 8.11.1 / AGP 8.9.2 / Kotlin 2.1.20 / Compose BOM 2025.04.01로 재현 가능하도록 고정했습니다. 최신 버전이라는 의미는 아닙니다. 호환성과 변경 범위를 확인하며 별도로 업데이트합니다.

## 두 눈 깜빡임 만들기

1. `☰` → **새 프로젝트**. 이름을 입력합니다.
2. **+ PNG**에서 왼쪽·오른쪽 눈 PNG를 함께 선택합니다. 원본은 앱 내부로 복사됩니다.
3. **파츠** 목록에서 눈을 선택합니다. 캔버스에서 드래그해 배치하고 **속성**에서 X/Y·회전·배율을 입력한 뒤 ✓를 누릅니다.
4. PNG는 기본 4×4 격자(25 정점) 메쉬로 들어옵니다. **메쉬 생성 / 재생성**에서 행·열을 바꿀 수 있습니다. 재생성은 선택한 파츠의 기존 키폼을 지우며 Undo로 되돌릴 수 있습니다.
5. **파라미터 추가**: 이름 `눈 개폐`, 최소 `0`, 기본 `1`, 최대 `1`.
6. 왼쪽 눈을 선택해 **눈 개폐 키폼**을 누릅니다. 오른쪽 눈에도 같은 파라미터로 반복합니다. 각각 제어하려면 파라미터를 따로 만듭니다.
7. 슬라이더 `0`은 닫힘, `1`은 열림, 중간 값은 선형 보간됩니다. 닫힘은 눈 메쉬의 세로 높이를 4%로 줄이는 기본 프리셋입니다.
8. 직접 키폼을 만들려면 원하는 파라미터 값 → **현재 값 키폼 편집** → 메쉬 정점 드래그 → **키폼 기록**. 미기록 초안은 자동 저장 대상이 아닙니다.
9. **저장** 후 앱을 재실행하면 마지막 프로젝트가 복구됩니다. `☰` → **프로젝트 내보내기**로 이미지가 포함된 `.mylive2d` 파일을 저장합니다.
10. 다른 기기에서는 `☰` → **.mylive2d 가져오기**. 기존 프로젝트를 덮어쓰지 않도록 새 프로젝트로 가져옵니다.

## 조작

- 한 손가락: 파츠 드래그 / 메쉬 모드 정점 드래그 / 빈 곳에서 카메라 이동
- 두 손가락: 확대·축소·카메라 이동
- **정밀**: 드래그 이동량 20%; 정점 선택 반경 28dp
- **그리드 / 스냅**: 100 모델 단위 격자 / 10 모델 단위 스냅
- **전체 보기**: 표시 중인 모델에 카메라 맞춤
- 레이어 목록 위쪽이 앞. 표시·숨김, 잠금, 앞/뒤 이동 지원
- 작은 화면은 좌우 패널을 버튼으로 전환하고 접어 캔버스를 확보합니다. 850dp 이상에서는 양쪽 패널을 각각 열 수 있습니다.
- `☰`: 한국어/English, 다크/라이트 전환, 최근 프로젝트 열기/삭제
- 프로젝트 이름을 누르면 이름 변경. `*`는 명시적으로 저장하지 않은 변경입니다. 자동 저장 후에도 명시적 저장 전까지 표시됩니다.

## 구현 범위

- 생성·이름 변경·최근 목록·로컬 삭제·저장·자동 복구·독립 프로젝트 가져오기/내보내기
- PNG 다중 가져오기, 파츠 위치·회전·균일 배율·투명도·잠금·표시·이름·복제·순서
- 규칙 격자 삼각형 메쉬 생성, 터치 정점 이동, 고정 UV 텍스처 변형
- 사용자 파라미터 범위·기본값·슬라이더, 눈 개폐 프리셋, 사용자 정점 키폼 기록/삭제, 선형 보간
- OpenGL 실시간 미리보기, 체크 배경/밝은 배경/어두운 배경, 확대·이동, 선택 강조
- 프로젝트 스냅샷 Undo/Redo(최대 40), 회전 시 ViewModel 상태 유지, 한/영·테마 설정 유지

## 미구현 / 제한

- Phase 2: 임의 정점 추가·삭제, 자유 삼각분할, 알파 윤곽 자동 메쉬, 그룹/부모-자식, 회전·워프 디포머, 고급 복수 파라미터 리깅
- Phase 3: 타임라인·키프레임·재생·루프·복수 애니메이션
- Phase 4: PSD, GIF/영상/투명 PNG 결과물 내보내기, 고급 태블릿 UI, 성능 계측
- Cubism 파일 호환·얼굴 추적·물리 연산 미지원
- 체크 배경은 투명 영역의 편집 미리보기입니다. 결과 이미지의 알파 내보내기는 아직 없습니다.
- 파츠당 한 파라미터로 사용자 키폼을 편집합니다. 여러 파라미터가 같은 파츠를 조작할 때 사용자 키폼 편집은 제한됩니다.
- 파일당 PNG 16 MiB, 가져오기 시 최대 변 2048로 샘플링. 프로젝트 최대 32 이미지 / 64 파츠 / 총 16,777,216 이미지 픽셀 / 32 파라미터 / 바인딩당 32 키폼.
- ZIP 해제 후 총 64 MiB / 메타데이터 8 MiB 제한. 메모리 부족을 줄이기 위한 보수적 상한이며 모든 저사양 기기에서의 성능을 보장하지 않습니다.
- 자동 저장 지연 약 0.8초 전의 강제 종료 또는 미기록 키폼 초안은 복구되지 않을 수 있습니다. Undo 이력은 앱 프로세스가 종료되면 초기화됩니다.
- 60FPS는 목표이며 실측 결과가 아닙니다. 저장/파일 입출력은 IO 코루틴, 렌더링은 변경 시에만 요청합니다.
